Caption fonts bundled for Symphony's WYSIWYG overlay preview.

- TikTok Sans: TikTok, SIL Open Font License 1.1
- Inter, Anton, Montserrat, Poppins, and Bebas Neue: Google Fonts, SIL Open Font License 1.1

The same font files are copied into `video-worker/fonts` so browser previews and final FFmpeg renders stay visually aligned.
